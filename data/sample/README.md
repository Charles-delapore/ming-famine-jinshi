# Synthetic sample data

**These are not real historical records.** Every value in this directory is
generated by `scripts/make_sample_data.py` with the fixed seed `20261113`.
The tables mirror the **column names and dtypes** of the Work_ming v5 result
tables so that the analysis code and figure scripts can be exercised without
redistributing the private famine/Jinshi tables or the licensed CHGIS basemap.

## Sources and provenance

- **Schema**: derived from the Work_ming v5 result tables (private research
  project). Column names and dtypes are preserved; values are synthetic.
- **Basemap**: Natural Earth 1:110m Admin 0 – Countries, public domain
  (<https://www.naturalearthdata.com/>), simplified to the China polygon and
  converted to EPSG:4326 GeoJSON. See the `source` property in the file.
- **Generation**: `python scripts/make_sample_data.py` (seed `20261113`).
- **No real historical record is present.** Do not use these files for
  substantive inference, only for code/figure smoke tests.

## Reproduce the figures on the samples

```bash
python scripts/make_sample_data.py        # regenerate (idempotent)
python scripts/run_sample_figures.py      # writes figures/sample/
```

The runner sets:

```
MING_OUTPUT   = data/sample
MING_BASEMAP  = data/sample/basemap_china.geojson
MING_FIG_DIR  = figures/sample
```

The output is a visual smoke test, not a substitute for the real figures in
`figures/`.
