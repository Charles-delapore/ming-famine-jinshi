# Data and reproduction notes

This repository contains **code, figures and documentation**, not the raw
historical datasets. The raw tables are third-party or private research data and
are not redistributed here.

## Expected local layout

```
<MING_DATA>/                     # default: <repo>/data/raw
├── table_citys.xlsx
├── table_level.xlsx
├── table_levels.xlsx
├── table_general.xlsx
├── table_general2.xlsx
├── table_general1627_1644.xlsx
├── table_generals1521_1619.xlsx
├── ming_general.csv
├── merged_data.csv
├── grid_data_20_load.csv
└── paleoclimate/
    ├── mann2009_nhall.txt
    ├── mann2009_amo.txt
    ├── schneider2015_temp.txt
    └── schneider2015_mxd.txt
```

The basemap is a separate path (`MING_BASEMAP`); the sample repository uses a
Natural Earth China outline, while the original analysis used a CHGIS-derived
province layer.

Set the environment variables before running the pipeline or figures:

```bash
export MING_DATA=/path/to/raw            # Windows: $env:MING_DATA = "C:\path\to\raw"
export MING_OUTPUT=/path/to/results      # optional; default ./output
export MING_PALEO=$MING_DATA/paleoclimate
export MING_BASEMAP=/path/to/province.shp  # optional; sample GeoJSON is the fallback
export MING_FIG_DIR=./figures             # optional
```

Then:

```bash
python run_pipeline.py                   # full pipeline (needs all raw tables)
python scripts/fig1_patterns.py          # figures from result tables
python scripts/fig2_mechanism.py
python scripts/fig3_framework.py
```

## Synthetic sample data

`data/sample/` contains deterministic synthetic tables generated by
`scripts/make_sample_data.py` (seed `20261113`). They mirror the result-table
columns but contain **no real historical records**. Use them to smoke-test the
code and figures:

```bash
python scripts/make_sample_data.py
python scripts/run_sample_figures.py     # writes figures/sample/
```

The sample basemap is Natural Earth 1:110m Admin 0 – Countries (public domain),
simplified to China.
